# Contextual collaboration calibration

All prompts are authored fictional data. Both poles of each preference axis appear in at
least two sessions. No complete role should be assigned. Opposite choices belong to different
tasks, never to an inferior or contradictory personality. Each of the four pacing/control
combinations appears twice; stepwise does not imply user-owned decisions, and whole-task does
not imply delegation. The prompt variants repeat a pattern but are not identical quotations.

The API and migration tasks have predefined criteria. Prototype work refines reviewed results.
No assistant replies or completed outcomes are supplied. Do not claim that tests passed,
time was saved or the user is expert. Absence of a specific understanding signal is unknown.
Review quote relevance manually: authentic quotations alone do not establish semantic support.
