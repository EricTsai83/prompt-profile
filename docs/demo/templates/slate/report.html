From your own prompts; each suggestion cites what it is based on來自你自己的 prompt；每個建議都標出根據

1

State the expected result first先講預期結果

You often describe the change and add the real requirement only after the first answer.你常先描述要改什麼，等第一次回答後才補上真正的要求。

Several follow-ups in this sample start with a correction such as “no, keep the old API”.這份樣本裡有幾個追問是以糾正開頭，例如「不對，保留舊的 API」。

Put the expected result and the constraints in the first prompt.在第一個 prompt 就寫出預期結果和限制。
