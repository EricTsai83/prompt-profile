# Research font asset

`BricolageGrotesque-latin.woff2` is the unmodified Latin variable-font file served by Google Fonts
for Bricolage Grotesque, optical size 12–96 and weight 200–800, retrieved on 2026-10-24.

Source: https://fonts.gstatic.com/s/bricolagegrotesque/v9/3y9K6as8bTXq_nANBjzKo3IeZx8z6up5BeSl9D4dj_x9PpZBMlGIInE.woff2

Project and licensing: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque

The complete SIL Open Font License is in `BricolageGrotesque-OFL.txt`. The asset's SHA-256 is
recorded in `../startup-screenshots/manifest.json`. The prototype uses local fonts; no font-service
requests are made by the captured page. Headless captures inline this asset as a data URL.

Inter is reused from the existing `src/report/fonts/` assets and their `Inter-OFL.txt` license.
These assets are for the research prototype; the npm bundle continues to use its existing fonts.
