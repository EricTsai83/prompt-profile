# Collaboration foundation acceptance

Phase C adds structured signature moves, scoped understanding signals and source coverage.
The core format is profile schema 15; analysis version 20 invalidates prior map/merge cache
entries. Released schemas 8 and 14 remain readable without inventing moves or understanding evidence. Older
reports say this was not assessed; missing evidence is not lack of competence.

## Mechanical guarantees

A signature move must refer only to selected, ordered episodes from at least two independent
conversations, each with at least two user turns. Its name and description are translated,
but episode IDs and source quotes are not. Context and sequence come from the cited episodes.
Benefit/cost claims require exact evidence from an explicitly user-reported ending; requests
and unknown endings cannot establish effects. Effect text stays attributed, not causal proof.

Understanding signals retain kind, task context, exact quotes, session/period spread and
basis. Requested practices and user reports are labeled separately. Autonomous agent actions
and tool questions are excluded. The five categories are context, uncertainty, tool boundaries,
verification and recovery. Missing categories remain unobserved. Counts do not grade expertise.

Preference support is capped at one contribution per conversation. Identical normalized
excerpts and identical whole source templates are independently deduplicated, so different
quoted fragments of a copied template cannot multiply recurrence. Paraphrased templates can
still escape this check, and identical meaningful short follow-ups can be undercounted.
Axis coverage reports conversations with cited choices, analysed conversations and periods.
It does not claim to measure every task eligible for a preference decision; uncited choices
remain unknown. No personality scores or population ranks are introduced.

Behavioral tests check malformed references, same-session recurrence, unsupported effects,
actor distinctions, translation without source quotes, visibility, legacy decoding, template
deduplication, coverage and bilingual rendering. The LLM JSON schema requires complete new
fields while the decoder tolerates omitted fields as unavailable, supporting older outputs.

## Bounded repeated evaluation — 2026-10-31

`experiments/collaboration-foundation.json` ran three entirely authored personas twice each,
using Claude Code default. Six cases used 24 attempts within a 30-attempt cap, with no failed
attempts or retries; both languages were requested. Each run reported `claude-opus-5-5`.
The ignored artifact is `eval-output/comparisons/20261030-160322-a4cb/` (the folder stamp is UTC).
All mechanical quality rubrics passed; that is not a semantic-truth result.

Manual reading against the authored sources found:

- Contextual collaborator: both characteristic ways on all four axes in both repetitions;
  no complete role. Both runs retain two recurring backend/prototype moves and requested
  verification/context practices. Benefits and costs remain null. Names vary while sequence
  and scope remain recognisable. One move description compresses result-based steering more
  strongly than the user-only sequence establishes; it is not a verified assistant outcome.
- Heavy questions: every preference axis is unobserved in both repetitions, without forcing a
  role or treating activity as expertise. Both runs show the recurring definition-question
  sequence. One clarification request is labeled as a requested uncertainty practice. One
  description suggests a concept had not landed; the source does not prove that interpretation.
- Sparse boundaries: both repetitions retain define-first and criteria-based closure, one
  isolated pacing choice and unresolved decision ownership. No recurring multi-turn move is
  invented from single-turn sessions. Requested checks, stated uncertainty and prior context
  remain separate signals, without a global expertise judgment.

These cases demonstrate repeat stability of the categorical decisions on this small authored
set, not scientific validation or general accuracy. Source relevance and compressed prose can
still overreach despite authentic citations and model review. The authored expectations and
manual findings remain separate from automated rubrics. Ordinary tests never spend quota.

Phase C's product contract is delivered at this bounded scope. Continued calibration belongs
to final integration and actual owner feedback; there is no external participant requirement.
