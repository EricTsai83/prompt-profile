# Plain-language fictional demo

The public examples and `pnpm dev:report` use `test/fixtures/profile.demo.json`.
The older `profile.sample.json` remains a compatibility and stress-test fixture, rather than
public-facing copy. The downloadable demo profile now matches the rendered report.

The new example contains eight authored prompts in four fictional conversations: a club website,
a registration form, an event notice and meeting notes. Statistics are computed from those eight
prompts. No personal history or model call was used to create this demo. English and Traditional
Chinese describe the same cases and leave quotations in their original Chinese.

The previous headline described a perfectionist arguing about naming at midnight. It was a
playful label, but did not help a new reader understand how the person works. The new headline
is “Explain the need, then refine the draft.” Move names describe observable actions: “Say what
should stay” and “Choose a draft, then adjust it”. Chapters name the old links, saved form data,
notice opening and meeting action items so readers can connect the description to each request.

The demo does not invent successful tests, time saved or a completed task. All episode endings
are unknown. Asking for two writing options does not establish a general stepwise-delivery
preference, so pacing and the complete role remain unresolved. The art is therefore neutral.
There are no invented deficiencies or coaching suggestions.

This changes authored demo data and preview wiring only. It does not rewrite saved user
profiles, change the analysis prompt or demonstrate that future model prose is easier to read.
Existing privacy controls and render-only language/look behavior remain in use. Reader feedback
is still needed to judge whether the simpler wording is useful.
