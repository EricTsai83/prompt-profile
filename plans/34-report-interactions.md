# Report interactions

Status: Planned; owner requested on 2026-10-31

## Outcome

Make optional report exploration feel interactive without hiding essential observations or
evidence. Keep offline rendering and explicit uncertainty. Hover definitions and keyboard
focus are the baseline; touch can pin definitions open using native disclosure controls.

## Acceptance

- [ ] Identify reader questions that benefit from interaction before choosing components.
- [ ] Give clickable controls clear affordances and distinct closed/open visual states.
- [ ] If transitions are added, distinguish active state and respect reduced-motion preferences.
- [ ] Preserve visible evidence, keyboard/touch access, mobile layouts and print equivalents.
- [ ] Validate both languages and dark/light modes using synthetic fixtures and owner feedback.

Follow the repository TDD and verification gates. Do not add new analysis calls or rewrite
stored prose merely to provide an interaction. This plan does not authorize a general redesign.
